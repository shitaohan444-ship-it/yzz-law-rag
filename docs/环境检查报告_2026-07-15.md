## 8. 警告与后续测试前提

1. **开发认证关闭**：`authentication=disabled`，适合本机直接测试，不代表生产权限已启用。
2. **首次模型加载尚未验证**：必须从一次真实 `/search` 开始观察模型加载时间、内存和错误。
3. **宿主机空闲内存偏低**：首次加载和并发测试期间运行 `docker stats`，发现 OOM、容器重启或系统明显换页时停止并发测试。
4. **存在历史非成功文档**：后续测试先识别 `failed=1`、`pending=1`、`skipped=2` 对应记录，不要直接全量重建或删除。
5. **历史基线已经变化**：Milvus 当前为 308 行，后续只比较“本次测试前后差异”。
6. **Node 平台 API 未由根 Compose 启动**：当前开发模式可直接测试 RAG API；生产网关和真实平台登录态不在本轮环境检查范围内。
